# PixelPet Sanctuary

A tiny Neopets-style browser pet game built with plain HTML, CSS, and JavaScript.

## Features

- Adopt a pet with a custom name and species.
- Manage hunger, happiness, energy, and health over time.
- Take actions: feed, play, rest, and adventure.
- Earn coins from adventures.
- Buy items in the shop and use them from inventory.

## Run locally

```bash
python -m http.server 4173
```

Then open <http://localhost:4173>.
